# Inventory Management System

Inventory Management System built using Django and Django REST Framework with scalable enterprise-level architecture.

---

# Tech Stack

- Python 3.10+
- Django 5.0.2
- Django REST Framework
- SQLite3
- django-cors-headers
- django-filter

---

# Features

## Authentication Ready
- DRF-based API architecture
- JWT authentication ready
- Scalable permission structure

## Product Management
- Product CRUD APIs
- SKU management
- Quantity tracking
- Product pricing

## Warehouse Management
- Warehouse CRUD APIs
- Warehouse capacity tracking
- Active / inactive warehouse management

## Inventory Movement
- Stock In
- Stock Out
- Stock Transfer
- Stock Return
- Inventory movement history

## Enterprise Architecture
- App-based architecture
- API separation
- Dedicated serializers
- Dedicated ViewSets
- Clean URL structure
- Future-ready scalable structure
